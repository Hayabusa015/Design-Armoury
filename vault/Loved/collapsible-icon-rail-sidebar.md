# Collapsible icon-rail sidebar

What it is: A sidebar design from a TikTok video that folds into an icon-only rail and unfolds back to full labels.

Why I like it: This TikTok had a sidebar I want.

Steal this:
- Fold to an icon-only rail, with a keyboard toggle and the state remembered between visits
- Labels blur out first, then the rail narrows, taking roughly 0.45 s; unfolding reverses it
- A sliding highlight bar marks the active page
- A count badge shrinks to a small dot when the rail is collapsed, and search becomes an icon button
- Use the project's own accent colour, not the video's

Avoid:
- none noted

Observed: The TikTok link itself cannot be fetched by Claude. This note comes from an earlier session that analysed frames from a screen recording the user supplied, so the details are from that review and were not re-checked today. A version was built into a desktop focus app.
