# Trade Gothic Next

What it is: A sans-serif type family with many weights and widths, chosen as the single font for two separate brand systems so that variety comes from weight and width, not from adding a second face.

Why I like it: not given. It was chosen as the one family carried across both brands, from a lab-notebook feel to a scoreboard feel.

Steal this:
- One family across a whole brand, varying only weight and width: Heavy Condensed for logos, Bold for headers, Regular for subheads, Light for body, Light Italic for captions, Condensed for data and tables

Avoid:
- Do not introduce a secondary face to a brand built on it.

Get it: Trade Gothic Next is a commercial family. Where it is licensed, and whether the existing licence covers web use, was not checked here. Treat as unknown before using it in a web build, and name a licensed fallback in the blueprint.
