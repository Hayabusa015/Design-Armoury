## Design character
Plain, tidy UI icons that sit naturally in Tailwind projects. Not verified: how they look.

## Best for
Tailwind UIs that want a small, neutral icon set with outline and solid variants.

## Avoid when
Svelte or Solid is the framework (not accepted upstream); a large or expressive library is needed (see `lucide`, `phosphor-icons`).

## What's inside
Outline (24x24) and solid (24x24, 20x20, 16x16) sets. Packages: `@heroicons/react`, `@heroicons/vue`.

## How to use
Install the React or Vue package and import icons by name and style.

## Gotchas
- Maintainers accept only bug fixes; no new icons or new framework support.
- Total icon count was not stated on the page.

## Overlaps and pairings
Smaller than `lucide` and `phosphor-icons`; choose it only when staying inside the Tailwind family matters.
